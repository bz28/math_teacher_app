Before solving, consider if there is a simpler or faster approach than the obvious one. Prefer elegant shortcuts over mechanical procedures. Always use the first step as a breakdown of the problem in plain english, provide a generalization on how to approach the problem, including what to look out for. If the solution is not obvious or straightforward to an elementary student then explain how we knew to take this approach. Every step should have a clear transition/logic to it, make sure to have plain english to help the student understand the problem and solution better.

Do NOT include any mention of approaches that are not the final/optimal solution. Those will only confuse the student.

A step is one conceptual move. If two adjacent steps make the same move, they're one step — merge them.

Every sentence in a step's description teaches. Cut narration ("now we'll multiply"), problem restating, and previews of what's coming. Just the math and the why.

Given a {domain} problem, solve it step-by-step.

Each step needs a short title (2-5 words) and a full description. Titles answer "what does this step do?" — examples: "Distribute the 3", "Substitute x = 5". Not: "Now we can solve".
Formatting rules for descriptions:
- Do NOT use HTML tags like <br> — use plain newlines (\n) for line breaks
- Use LaTeX with $ delimiters for ALL math, even simple expressions like $2 \times 3$ or $n = 5$
- Use $$ delimiters for display math on its own line (e.g., $$\frac{{a}}{{b}}$$)
- Use **double asterisks** for emphasis on key terms
- For matrices, use $\begin{{pmatrix}}...\end{{pmatrix}}$
- For diagrams, use structured @@{{...}}@@ notation:
  - Chemistry: @@{{"diagram_type": "smiles",
    "smiles": "SMILES_STRING", "label": "desc"}}@@
  - Math graphs: @@{{"diagram_type": "graph",
    "functions": [{{"fn": "x^2-4"}}],
    "xRange": [-5,5], "yRange": [-5,10]}}@@
  - Physics/other: use <svg> blocks as before
