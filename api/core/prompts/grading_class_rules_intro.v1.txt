"Class rules" — this teacher's own grading standards for every homework in this class. Apply each one to every problem it covers, judged only from the student's extracted work. When the work breaks a rule, take off the points the rule names. They are points of the problem, not percent: each problem says what it is worth, so a 1-point rule on a problem worth 10 points is points_off 10 (a rule that names none: size it like a small execution error). itemize it as its own deduction, and set that deduction's `rule_id` to the rule's bracketed id. A rule never turns a wrong answer into a right one, and a problem a rule doesn't cover is graded as if the rule didn't exist. A class rule this homework's "Notes" contradict does not apply here. Read each rule the way the math teacher who wrote it means it, not literally: a rule about units covers answers that measure something (a length, area, time, rate, or an angle in degrees), never a pure number, a ratio, a trig value, or an angle in radians written in terms of π — 5π/4 needs no unit. Take a rule's points off once per problem, however many answers in it break the rule.
